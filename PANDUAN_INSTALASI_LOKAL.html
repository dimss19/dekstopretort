Instalasi Sekali Jalan (Tanpa XAMPP / Plug & Play)

Sangat mudah! Tidak perlu menginstall software web server tambahan apa pun.

1

Ekstrak Folder

Ekstrak file zip ke folder mana pun di komputer Anda (misal: C:\SCADA-Retort atau di Desktop).

2

Pasang Driver USB-to-RS485 CH340

Buka folder drivers\ lalu klik kanan install_driver_ch340.bat → pilih Run as administrator. Klik tombol INSTALL hingga muncul pesan sukses.

3

Jalankan START_SCADA.bat

Dobel-klik file START_SCADA.bat. Server otomatis aktif dan web browser Anda akan langsung terbuka ke alamat http://localhost:8000.

4

Ikuti 7 Langkah Web Installer di Browser

  • Langkah 3 (Lisensi): Masukkan salah satu kode demo di atas.
  • Langkah 4 (Database): Pilih SQLite (Otomatis) → tidak perlu konfigurasi MySQL!
  • Langkah 5 (Akun): Masukkan email & password administrator yang Anda inginkan.
  • Langkah 6 (Selesai): Klik tombol Install dan sistem SCADA siap digunakan!
5

Buat Shortcut Desktop untuk Operator

Dobel-klik CREATE_DESKTOP_SHORTCUT.bat. Ikon shortcut "SCADA Retort - Indah Mesin" akan otomatis muncul di Desktop Windows.

Panduan Kabel & Hardware Device (Autonics TNS / TNH / TNL)

Penjelasan koneksi fisik Modbus RTU RS-485 dongle USB ke terminal controller.

TNS (Ukuran 48x48 mm)
  • • Terminal A (+) → Skrup A (+) Converter
  • • Terminal B (-) → Skrup B (-) Converter
  • • Power: Pin 5 & 6 (220V AC)
TNH (Ukuran 48x96 mm)
  • • Pin 13 (A+) → Skrup A (+) Converter
  • • Pin 14 (B-) → Skrup B (-) Converter
  • • Power: Pin 11 & 12 (220V AC)
TNL (Ukuran 96x96 mm)
  • • Pin 14 (A+) → Skrup A (+) Converter
  • • Pin 13 (B-) → Skrup B (-) Converter
  • • Power: Pin 11 & 12 (220V AC)
